# 2025-11-16 - UI 레이아웃 개선

## 디자인 개선 시작

UI를 개선하기로 했다. 슬슬 거의 끝나간다.

일단 첫 번째로 테이블 헤더를 봤다. "액션"이라는 단어가 너무 추상적이었다. 실제로는 수량을 입력하는 컬럼이니까 "수량"이 훨씬 명확하다.

프로모션과 수량 컬럼의 정렬을 조정했다. 처음에는 전부 왼쪽 정렬이었는데, 프로모션은 중앙, 수량은 중앙이 더 보기 좋았다. 가격은 숫자니까 오른쪽 정렬이 맞다고 생각했다. 재고도 숫자라서 오른쪽 정렬로 바꿨다.

## CSS 텍스트 정렬 학습

CSS에서 텍스트 정렬을 조정하는 방법을 정리했다.

`text-align` 속성은 인라인 콘텐츠의 정렬을 제어한다. left, center, right, justify가 있다.

테이블에서는 헤더(`<th>`)와 셀(`<td>`) 각각에 text-align을 적용할 수 있다. nth-child 선택자를 사용하면 특정 컬럼만 정렬을 바꿀 수 있다.

```css
th:nth-child(2) {
  text-align: right;
  padding-right: 2rem;
}
```

이렇게 하면 두 번째 컬럼(가격)만 오른쪽 정렬이 된다.

## 색상 대비 개선

UI를 보니까 글씨가 전반적으로 흐릿했다. `#999` 같은 연한 회색을 많이 쓰고 있었다.

접근성을 생각하면 텍스트와 배경의 대비가 충분해야 한다. WCAG 기준으로 최소 4.5:1의 대비율이 필요하다.

흐릿한 색상들을 전부 진하게 바꿨다.

- 장바구니 빈 메시지: `#999` → `#666`
- 상품 수량: `#555` → `#2c3e50`
- 품절 상품: `#999` → `#666`
- 프로모션 없음(-): `#ccc` → `#999`

영수증도 마찬가지였다. Courier New 폰트에 연한 색상이 조합되니까 더 읽기 어려웠다. 모든 텍스트에 `color: #2c3e50`을 적용했다.

멤버십 체크박스 글씨도 흐릿했다. 이것도 `#2c3e50`으로 바꿨다.

## 장바구니 레이아웃 개선

장바구니 박스를 보니까 좌우에 빈 공간이 많았다. `max-width: 400px`로 고정되어 있어서 그리드 컬럼을 다 채우지 못하고 있었다.

`max-width`를 제거하고 `width: 100%`로 바꿨다. 이제 장바구니가 할당된 그리드 영역을 꽉 채운다.

## width vs max-width 차이

이 기회에 width와 max-width의 차이를 정리했다.

`width: 100%`는 부모 요소의 너비를 100% 채운다. 부모가 400px이면 400px, 600px이면 600px이 된다.

`max-width: 400px`는 최대 너비를 400px로 제한한다. 부모가 600px이어도 400px을 넘지 않는다. 하지만 부모가 300px이면 300px로 줄어든다.

반응형 디자인에서는 보통 둘을 조합한다. `width: 100%`와 `max-width: 1200px`를 함께 쓰면 작은 화면에서는 꽉 차고, 큰 화면에서는 1200px까지만 늘어난다.

장바구니는 그리드 컬럼 안에 고정되어 있으니까 `width: 100%`만 써도 충분하다. 그리드가 이미 크기를 제한하고 있기 때문이다.

## CSS Grid 레이아웃 복습

App.vue를 보니까 그리드로 레이아웃을 구성하고 있었다.

```css
.container {
  display: grid;
  grid-template-columns: 1fr 400px;
  gap: 2rem;
}
```

첫 번째 컬럼은 `1fr`로 남은 공간을 전부 차지한다. 두 번째 컬럼은 `400px` 고정이다. gap은 컬럼 사이 간격이다.

처음에 장바구니를 늘리려고 `grid-template-columns: 1fr 600px`로 바꿨는데, 전체 레이아웃이 이상해졌다. 상품 테이블이 너무 좁아졌다.

원래대로 돌리고, 대신 장바구니의 `max-width`를 제거하는 방식으로 해결했다. 그리드 구조는 그대로 두고, 내부 요소만 조정하는 게 더 안전했다.

장바구니 위쪽 여백도 조정했다. `margin-top: 4rem`을 추가해서 상품 테이블 헤더와 비슷한 높이에서 시작하게 만들었다.

## CSS 박스 모델

padding과 margin을 조정하면서 박스 모델을 다시 생각했다.

박스는 안쪽부터 content, padding, border, margin 순서다.

padding은 콘텐츠와 테두리 사이 공간이다. 배경색이 padding까지 적용된다. `padding: 1.5rem`은 상하좌우 모두 1.5rem이고, `padding: 1.5rem 1rem`은 상하 1.5rem, 좌우 1rem이다.

margin은 테두리 밖 공간이다. 다른 요소와의 간격을 만든다. `margin: 4rem auto 0`은 위 4rem, 좌우 auto(중앙 정렬), 아래 0이다.

장바구니에서 처음에 `padding-top: 5rem`을 넣었는데, 이러면 흰 박스 안쪽에 빈 공간이 생긴다. 원하는 건 박스 바깥쪽 여백이니까 `margin-top`이 맞다.

---

UI 개선 작업에서 CSS 기본기를 복습했다. text-align, padding, margin, width 같은 속성들은 자주 쓰지만 정확히 이해하고 쓰는 게 중요하다. padding-left로 오른쪽 이동, padding-right로 왼쪽 이동하는 것처럼 방향이 헷갈릴 때가 있다.

색상 대비도 중요하다. 디자인적으로 연한 회색이 세련되어 보일 수 있지만, 가독성이 떨어지면 사용자 경험이 나빠진다. 특히 영수증처럼 정보 전달이 핵심인 UI에서는 명확한 대비가 필수다.

width와 max-width의 차이, 그리드 레이아웃의 작동 방식 같은 것들도 정리할 수 있었다.
